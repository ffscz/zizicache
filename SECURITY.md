# Security policy

## Reporting a vulnerability

Please do not report security problems in a public issue or discussion.

Send the report through the [contact form on zizicache.com](https://zizicache.com/contact/) with the subject "Security". Include the ZiziCache version, the steps to reproduce and what an attacker could do. We confirm the report, fix the problem in a new release and credit you in the changelog if you wish.

## Supported versions

Only the latest release of ZiziCache gets security fixes. The plugin updates itself from the WordPress admin, see [Updates, Downgrade and Logs](https://zizicache.com/doc/updates-downgrade-logs/).
